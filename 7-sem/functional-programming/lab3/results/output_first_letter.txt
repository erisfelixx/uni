2.1 Типи в Haskell
 Мова програмування Haskell
 Мова програмування Haskell назваа на честь америкнського
матеатика Гаскелла Каррі (Haskell Curry), роботи якого в галузі матеатичної
логіки є базовими для функціонального програмування. Haskell є строго
типізованою виняткоо функціональною мовою, в оснві якої безпосередньо
лежить лямбда-чисення.
 Однак ситема типів мови Haskell відрізняється від ситем типів
більшості мов, в певній мірі вона є багатшою.

 Типи та значення
 Оскільки Haskell є чисто функціональною мовою, всі обчислення
здійснюються за допомогою обчислення виразі (синтакичних термів), що
повертають значення (абстрктні сутноті, які розглядаються як відпоіді).
 Оснвні типи в мові Haskell:
 • Char – символьний тип,
 • Bool – True або False,
 • Int – цілочисельний тип; його розмі може бути 32 або 64 біти залежно
 від архітектури,
 • Integer – «нескічее» ціле,
 • Double – дробове число (з плаваючою крапою).
 Кожне значення має з пов’язаний з ним тип. На інтуїтивному рівні
можна розглядати типи як множини значень.
 Приклади виразі включають як атомрні значення (атоми), такі як ціле
число 5, символ 'a' і функція \x -> x+1, так і структуровані значення, такі як
спиок [1, 2, 3] або пара ('b', 4).
 Так само як вирази позначають значення, вирази типу є синтакичними
термами, які позначають значення типу (або просто типи). Прикладами виразі

типу можуть бути атомрні типи Int (цілі необмежеого діапазону), Char
(символи), Int->Int (функції, що відображають Int в Int), а також
структуровані типи [Int] (однрідний спиок цілих) та (Char, Int) (пара із
символу та цілого).
 Всі значення в Haskell є сутнітю «першого класу»: вони можуть
передаватися в функції як аргументи, повертатися з них як результати,
розміщуватися в структурах даних тощо.
 З іншого боку, типи у Haskell – не «першокласні» сутноті. Насправді,
типи описують значення; зв'яування деякого значення з його типом
називається типізацією. Розглянемо приклади:
 5 :: Int
 'a' :: Char
 inc :: Int -> Int
 [1,2,3] :: [Int]
 ('b',4) :: (Char,Int)
 Функції Haskell завичай визначаються як набір рівнянь. Наприклад,
функція inc може бути визначена одним рівнянням:
 inc n = n + 1
 Статична ситема типів мови Haskell визначає формальний зв'яок між
типами та значеннями. Статична ситема типів гарантує, що програми на
Haskell «типобезпечні», тобо програміст не допустив будь-якої плутанини в
типах. Наприклад, не можна склати два символи, тому вираз 'a' + 'b' є
неправильо типізованим.
 Оснвна перевага статично типізованих мов загальновідома: всі
помилки типізації вияляються під час компіляції. Однак ситема типів не
перехолює помилки в повному обсязі: вираз 1/0 є вірним за типом, але його
обчислення призведе до помилки під час виконання.

 Поліморфні типи
 До складу Haskell включено також поліморфні типи – типи, які певним
чином містять квантор загальності над усіма типами.
 Вирази з поліморфними типами за своєю сутнітю описують сімейтва
типів. Наприклад, (forall a) [a] – це сімейтво типів, що складаєтья з типів
спику з елмнтами із a, для будь-якого типу a.
 Спиок цілих (наприклад, [1, 2, 3]), спиок символів (['a', 'b', 'c']), спиок
цілих спиків тощо будуть членами цього сімейтва, тоді як [2,'b'] туди не
належатиме, оскільки не існує однг типу, який включа би і 2, і 'b'.
 Спиок [1, 2, 3] у Haskell насправді є скороченою формою запису для
спику 1:(2:(3:[ ])), де [ ] – це порожній спиок, а «:» – інфксний оператр,
який доає свій перший аргумент на початок свого другого аргументу (деякого
спику). (Зауважимо, що оператри «:» та «[ ]» відпоідають cons і nil у мові
Lisp.) Оскільки оператр «:» правоасоціативний, можна також записати цей
спиок як 1:2:3:[ ].
 Розглянемо приклад функції яка підраховує кільість елмнтів у
спику:
 length :: [a] -> Int
 length [] = 0
 length (x:xs) = 1 + length xs
 Цей приклад підкреслює важлиий аспект мови Haskell: зіставлення зі
зраком (pattern matching).
 Ліві частини рівнянь містять зраки, такі як [ ] і x: xs.
 При застосуванні функції ці зраки зіставляються з фактичними
параметрами інтуїтивно зроумілим спообом ([ ] відпоідає тільки
порожньому спику, а x: xs буде успішно зіставлений з будь-яким спиком, що
містить хоча б один елмнт, при цьому x зв'яується з першим елмнтом, а
xs – з рештою спику).
 Якщо співтавлення пройшло успішно, права частина рівності
обчислюється і повертається як результат застосування функції. Якщо
